## Mandatory Requirements:

### 1. Code Structure

- Import and initialize Page classes written in Step 3
- Use Data Generator from Step 4
- Divide code according to **Arrange → Act → Assert** pattern

```
Arrange: Setup data, initialize pages
Act:     Perform actions (navigate, fill, click)
Assert:  Verify results (verify, expect)
```

### 2. Assertions (Verification)

- **MANDATORY** to have assertion at the end of each test case
- Should have assertions interspersed at important steps
- Assertions must be clear, correctly describe expected behavior

Playwright:
```typescript
await expect(page.getByText('Login successful')).toBeVisible();
await expect(page).toHaveURL(/dashboard/);
```

Selenium/TestNG:
```java
Assert.assertTrue(dashboardPage.isDisplayed(), "Dashboard should be visible after login");
Assert.assertEquals(driver.getTitle(), "Dashboard");
```

### 3. Smart Waits

- ⛔ **ABSOLUTELY** do not use: `Thread.sleep()`, `page.waitForTimeout()`, `time.sleep()`
- ✅ Playwright: Utilize auto-waiting + `expect().toBeVisible()`
- ✅ Selenium: Use `WebDriverWait` + `ExpectedConditions`

### 4. Test Independence

- Each test case **independent** (does not depend on other tests)
- Clear setup/teardown (`beforeEach`, `afterEach` / `@BeforeMethod`, `@AfterMethod`)
- Test data unique each run

### 5. Self-fix Loop (Auto-fix Mode)

After generating code, AI **must automatically run test**:
1. Execute test via terminal
2. If **PASS** → DONE, proceed to Step 6
3. If **FAIL** → Read error log → Analyze root cause → Fix code → Rerun
4. Repeat until stable PASS
5. **DO NOT ask user** during self-fix process (unless discovering unclear business rule)
